# Drugs DB Project
To start the backend and frontend, from the root of the project, run `npm run dev` after installing dependencies

# Install dependencies
From root of the project
1. `cd backend && npm i`
2. `cd frontend && npm i`   

# Setup DB   
1. Install MySQL Server and enter the username and password in the .end.dev file which needs to be created parallel to .env.template file
2. cd into backend dir and then run `npm run db:create` and then `npm run db:seed`   
   
Web server runs at **3000**   
Frontend runs at **5173**
